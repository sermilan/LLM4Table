# LLM4Table 前端说明

## 依赖安装

```bash
npm install
```

## 开发环境

```bash
npm run dev
```

## 构建生产版本

```bash
npm run build
```

## 新增功能

### 图表可视化功能
本系统集成了以下图表库用于数据质量评估的可视化：
- Recharts: 用于渲染柱状图和折线图
- 图表类型包括：
  - 表格形式（默认）
  - 柱状图
  - 曲线图

### CSV数据预览优化
数据下载模块的CSV预览功能已优化：
- 支持表格形式显示CSV数据
- 支持数据搜索功能
- 自动解析CSV文件并以表格形式展示
